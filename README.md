## ⚙️ 这个榜是怎么运作的

这是一个会自己干活的仓库，没有服务器、没有人工值守：

1. **后厨（爬虫）**：`crawler.py` 通过 GitHub 官方接口抓取 AI 领域 star 最高的项目与近 90 天的新星；
2. **仓库（数据）**：结果存入 `data/latest.json`，并自动刷新本页榜单区；
3. **闹钟（GitHub Actions）**：`.github/workflows/daily.yml` 每天北京时间 08:30 在 GitHub 的免费机器上自动运行爬虫，有变化就自动提交——仓库自己更新自己；
4. **脑子（点评）**：上方「书记点评」由人工（+AI 助手）定期精选撰写，机器只负责摆数据，判断永远是人的。

想拿去改成你自己的雷达？Fork 随意，改 `crawler.py` 里的搜索词就能盯任何领域。
